# Images

Static image assets for the Vanilla Co. site.

- `product-logos/` — small square icon/logo images used by the product
  category filter buttons (replaces the emoji icons). Drop in your own
  PNG/SVG logos and update the `logo` path in
  `js/data/categories.data.js` to point at them. Recommended size:
  64x64px (or any square image — it's displayed at 56x56px with
  `object-fit: contain`).
