# MEXA Branding Website

Welcome to the MEXA Branding Website project! This project is designed to showcase the branding company "MEXA" with a modern, single-page layout featuring a parallax effect.

## Project Structure

The project is organized into the following structure:

```
mexa-branding-website
├── index.html                # Main HTML file
├── css                       # Stylesheets
│   ├── main.css              # Main styles
│   ├── variables.css         # CSS variables for color palette
│   └── components            # Component-specific styles
│       ├── header.css        # Header styles
│       ├── hero.css          # Hero section styles
│       ├── partners.css       # Partners section styles
│       ├── brands.css        # Brands section styles
│       ├── parallax.css      # Parallax effect styles
│       └── footer.css        # Footer styles
├── js                        # JavaScript files
│   ├── main.js               # Main JavaScript file
│   └── components            # Component-specific scripts
│       ├── parallax.js       # Parallax effect script
│       ├── partners.js       # Partners section script
│       └── brands.js         # Brands section script
├── components                # HTML components
│   ├── header.html           # Header component
│   ├── hero.html             # Hero component
│   ├── partners.html         # Partners component
│   ├── brands.html           # Brands component
│   └── footer.html           # Footer component
├── fonts                     # Font files
│   └── README.md             # Font usage information
└── README.md                 # Project documentation
```

## Features

- **Single Long Scrolling Page**: The website is designed for smooth scrolling, providing a seamless user experience.
- **Parallax Effect**: The website includes a parallax scrolling effect to enhance visual engagement.
- **Responsive Design**: The layout is responsive, ensuring a good experience on both desktop and mobile devices.
- **Modern Aesthetic**: The color palette includes greens, beige, black, and white, with modern fonts for a contemporary look.

## Setup Instructions

1. Clone the repository to your local machine.
2. Open the `index.html` file in your web browser to view the website.
3. Customize the content in the `components` folder as needed to fit your branding requirements.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Parallax Scrolling

Feel free to explore and modify the project as needed!
